# SUPERSTES

**v1.1.0.** A short narrative web game in two chapters. Plain HTML/CSS/JS, no build step, no
backend, no persistence.

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

**Play it: <https://longshuicy.github.io/TESTIS/>**

> The GitHub repo is still named `TESTIS`; the play URL keeps that path until the repo is renamed so
> Pages does not break. GitHub will redirect the old path once renamed.

## Run it

Open `index.html` directly, or serve it:

```bash
python3 scripts/dev_server.py
# or: python3 -m http.server 8777
```

Then visit <http://localhost:8777>. Everything loads via plain `<script>` tags sharing globals, so
`file://` works too — no ES modules, no server dependency.

## Layout

```
index.html
css/style.css
js/i18n.js         I18N — locale registry, the ?lang= switch, English UI strings
js/scenes.js       SCENES_C1 — Chapter I scene data
js/endings.js      ENDINGS_C1 + WITNESS_CALLBACK_C1
js/wall.js         WALL_C1 — Chapter I tally wall copy
js/scenes-c2.js    SCENES_C2 — Chapter II scene data
js/endings-c2.js   ENDINGS_C2 + DEPARTURE_CALLBACK
js/wall-c2.js      WALL_C2 — Chapter II tally wall copy
js/content-zh.js   generated Chinese pack — do not edit; built from content/zh/
js/chapters.js     chapter registry; points SCENES/ENDINGS/WALL at one chapter
js/audio.js        AUDIO state + the Sound facade
js/gallery.js      the tally wall (art gallery)
js/main.js         state machine, rendering, events
assets/images/     art (WebP); Ch I per superstes-art-prompts.md, Ch II per chapter-2 art doc
assets/images/thumbs/  400px wall thumbnails, generated by the same script
assets/sound/      audio, filenames per docs/superstes-sound-design.md
assets/widgets/    standalone HTML prototypes; not loaded by the game
content/zh/        hand-edited JSON masters for the Chinese translation
scripts/           asset pipeline; not loaded by the game
ATTRIBUTIONS.txt   required credits; maintained from sound doc §11
```

Load order matters: `i18n.js` → every chapter's data files → the translation packs →
`chapters.js` → `audio.js` → `gallery.js` → `main.js`. See `index.html`.

## Languages

English is the default. Chinese is at **`?lang=zh`**, or through the toggle under the sound button
— a standing control, live for the whole run, showing the language it offers (`文` while you are
reading English, `A` while you are reading Chinese).

Switching mid-run costs nothing: the page does not reload. The scene, the chapter, every flag, the
carved name and the tally wall's count all survive; only the current scene's questions are asked
again. Language lives entirely in the URL — there is no persistence anywhere in this game — so the
URL is rewritten in place, keeping any other query params.

The Chinese is set in a 楷体 (LXGW WenKai), not a Song face: the story is one person remembering
out loud, and kai is the closest Chinese equivalent to the hand the English is set in.

The Chinese text is hand-edited as pure JSON in `content/zh/`, then wrapped into the committed
`js/content-zh.js` that the page loads:

```bash
scripts/build_content.py --check zh   # validate against the English structure
scripts/build_content.py zh           # write js/content-zh.js
```

Never hand-edit `js/content-zh.js`. See
[docs/superstes-localization.md](docs/superstes-localization.md) for the full contract, including
what deliberately stays untranslated (the Morse, the wordmark, every id and flag value) and how to
add a language.

## Art

Art generated with Midjourney from the author's prompts, with post-generation drawing and editing
in Procreate. The style derives from the author's own zodiac illustration series; prompts and style
rules live in [docs/superstes-art-prompts.md](docs/superstes-art-prompts.md) (Chapter I) and
[docs/superstes-chapter-2-art-prompts.md](docs/superstes-chapter-2-art-prompts.md) (Chapter II).

Every plate can be seen in-game on the tally wall, the page an ending leads to — inked with whatever
that run witnessed, with the rest left as tally marks. Open Chapter I's complete with `?all`,
Chapter II's with `?all=ii`.

Shipped art is WebP, downscaled from PNG masters by `scripts/optimize_images.sh`. That script also
writes the 400px `assets/images/thumbs/` tier the tally wall uses. Chapter II needs an extra prep
step first (`scripts/prepare_chapter2_art.sh`) because its masters arrived in a different palette —
see CLAUDE.md. Masters are git-ignored; don't hand-edit `assets/images/`.

## Music

Beds, stings, and the Morse drip are licensed tracks and Freesound recordings, re-encoded from
git-ignored 320kbps/24-bit masters by `scripts/optimize_audio.sh` (never edited in place). Shipped
format is mostly AAC (`.m4a`); three files stay uncompressed WAV for loop gaplessness or trigger
latency: `bed-scene-5.wav`, `drip-single.wav`, and Chapter II's continuous drip bed
`bed-c2-drip.wav`. See [docs/superstes-sound-design.md](docs/superstes-sound-design.md) for the full
cue list, the three earned silences, and the toggle.

Chapter II has no music of its own — only that drip, start to finish.

## Debug jumps

A URL parameter seeds flags and jumps straight to a scene or ending:

```
?debug=ending-a&looked_away=true&witness_reaction=reached&player_name=Aurelia
?debug=scene-4&examined=tally,astrolabe
?chapter=ii
?debug=c2-scene-7
?all=ii
```

`?chapter=ii` starts Chapter II from its first scene. A `?debug=c2-…` target implies Chapter II
without needing `?chapter=ii` as well. See `applyDebug` / boot in `js/main.js`.
